# ADR-007 – Branchenregeln in Industry Modules

STATUS: PROPOSED  
Bezug: MG-000 / SLG-000.2 / T-0002  
Decision-Log-Referenz: D-0007 (vorgeschlagene Zuordnung; keine Änderung an D-0007)

## Context

WFWSimulation soll langfristig mehrere Branchen unterstützen. CP-0001 schlägt vor, einen allgemeinen Business-Simulationskern von Branchenlogik zu trennen.

## Decision

**PROPOSED:** Allgemeine Unternehmens- und Simulationsregeln werden im Core beschrieben. Branchenspezifische Leistungs-, Kapazitäts-, Produktions-, Bestands- und Marktregeln werden als Industry Modules behandelt.

## Rationale

Eine Branche soll nicht tief in allgemeine Unternehmenslogik eingebaut sein. Getrennte Branchenmodule erlauben fachliche Erweiterung bei erkennbarer Core-Verantwortung.

## Consequences

- Der Core benötigt definierte Erweiterungspunkte.
- Branchenregeln und Modulversionen müssen für Replay nachvollziehbar sein.
- Ein Modul darf Accounting-Regeln nicht umgehen.
- Startbranche und Modulvertrag bleiben offen.

## Alternatives

- Eine Branche fest in den Core integrieren.
- Für jede Branche eine vollständig getrennte Anwendung entwickeln.
- Ein universelles Regelsystem ohne explizite Branchenmodule annehmen.

## Status

PROPOSED – nicht freigegeben.
