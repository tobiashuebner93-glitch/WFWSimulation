# ADR-005 – OpenTycoonOS zunächst als Referenz

STATUS: PROPOSED  
Bezug: MG-000 / SLG-000.2 / T-0002  
Decision-Log-Referenz: D-0003 (vorgeschlagene Zuordnung; keine Änderung an D-0003)

## Context

CP-0001 hält OpenTycoonOS zunächst als Referenz fest. Der Decision Log führt D-0003 mit dem Status PROPOSED und dem Inhalt „Keine Kernabhängigkeit“. CP-0002 weist OpenTycoonOS im damaligen Repository-Stand nicht als technische Abhängigkeit nach.

## Decision

**PROPOSED:** OpenTycoonOS wird zunächst als Referenzarchitektur betrachtet. Diese ADR beschließt weder eine Dependency noch eine Integration. Einzelne Konzepte können später separat bewertet werden.

## Rationale

Die Referenzeinordnung hält eine spätere Prüfung einzelner Konzepte offen, ohne eine Integration oder Kernabhängigkeit vorauszusetzen.

## Consequences

- Benötigte Kernregeln werden von WFWSimulation spezifiziert.
- Eine spätere Nutzung einzelner Komponenten benötigt eine gesonderte Prüfung ihrer Eignung.
- Lizenz, API, Wartbarkeit und Integrationsaufwand sind vor einer konkreten Übernahme zu untersuchen.
- Keine OpenTycoonOS-Komponente wird durch diese ADR als integriert vorausgesetzt.

## Alternatives

- OpenTycoonOS als Kernabhängigkeit übernehmen.
- Einzelne Komponenten unmittelbar übernehmen.
- OpenTycoonOS vollständig aus weiteren Architekturüberlegungen ausschließen.

## Status

PROPOSED – nicht freigegeben.
