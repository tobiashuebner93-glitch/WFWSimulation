## Reviewstand

A03-Cross-Review der integrierten UI ist PASS innerhalb des nicht-postenden Finanzumfangs: Preis/Kalkulationssnapshot werden nicht durch Annahme verändert; Leistung/Fertigstellung führt nicht automatisch zu Lieferung, Kundenabnahme, Rechnung, Steuer, Cash oder Ledger. Bericht: `docs/accounting/a03-t0069-run-ui-finance-cross-review.md`.

A09-Review ist NONPASS mit zwei reproduzierbaren UI-Adapterdefekten:

1. `submitRunOffer` mappt jedes `variableCost` außer exakt `'true'` still auf fix (`false`). Manipuliertes/fehlendes Enum `tampered` kann die Kostenbasis und DB I ändern; Eingabe muss fail-closed validiert werden.
2. `installRunOperatingResources` akzeptiert Ressourcenkonfiguration nach Run-/Tagesbeginn, obwohl die UI das Formular ausblendet. Die Ressourcenkonfiguration muss vor dem ersten Tagesereignis festgeschrieben werden, sofern nicht eine ausdrückliche, konsistent sichtbare Produktregel existiert.
