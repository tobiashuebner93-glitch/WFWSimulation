# Checkpoint CP-0004

Datum: 2026-09-25
Agent: A01 MASTER_ORCHESTRATOR
Status: COMPLETED
Bezug: MG-000 / SLG-000.1 / T-0001

## Anlass

Wiederholte GitHub-Connector-Schreibversuche wurden trotz fehlender Schreibberechtigung mit HTTP 403 abgewiesen. Um Wiederholungen dauerhaft zu verhindern, wurde der Schreibprozess projektweit präzisiert.

## Gesicherte Governance-Regel

- Der GitHub-Connector ist für dieses Projekt ausschließlich READ-ONLY.
- Über den Connector sind keine create-, update-, delete-, branch-, PR-, commit- oder sonstigen Schreiboperationen erlaubt oder zu versuchen.
- Remote-Schreibvorgänge erfolgen ausschließlich über den lokalen Git-Workspace und GitHub Desktop, sofern lokaler Schreibzugriff verfügbar ist.
- Bei fehlendem lokalem Schreibzugriff werden keine weiteren Schreibversuche unternommen. Der Blocker wird gemeldet und die fertigen Änderungen werden als Copy-Paste-Artefakt für den Benutzer bereitgestellt.

Die Regel wurde in `AGENTS.md`, `docs/agent-system/preflight.md` und `docs/agent-system/collaboration-state.md` verankert.

## Änderungsumfang

Nur Governance-Dokumentation geändert. Keine Architekturentscheidung oder ADR wurde verändert oder freigegeben. Keine Code-, Dependency- oder Supabase-Änderung vorgenommen.
