# Checkpoint CP-0053

Datum: 2026-10-25

Bezug: MG-000 / SLG-000.2 / T-0008 / D-0029 / D-0028 / D-0027 / CP-0052

## Nutzerentscheidung

Nach der formellen Mahnung erfolgt in V1 keine weitere Eskalation bis Pfändung oder Liquidation. Solche Ereignisse sollen in einer späteren Version hinzukommen.

Der abgestimmte Mahnfluss bis einschließlich formeller Mahnung lautet:

- erste Zahlungserinnerung zehn Kalendertage nach erstem fehlgeschlagenem Zahlversuch (D-0027)
- formelle Mahnung 14 Kalendertage nach der Zahlungserinnerung (D-0028)
- danach in V1 keine weitere Eskalation bis Pfändung oder Liquidation (D-0029)

## BGB-Abgleich

§ 286 BGB enthält keinen festen gesetzlichen 14-Tage-Abstand zwischen Zahlungserinnerung und Mahnung. Die Frist in D-0028 ist als Spielregel dokumentiert. Quelle: [§ 286 BGB](https://www.gesetze-im-internet.de/bgb/__286.html).
