# Checkpoint CP-0146

Datum: 2026-10-26  
Agent: A01 – MASTER_ORCHESTRATOR  
Status: V1-Geschäftsjahr auf zwölf Monate bis Kalenderjahresende festgelegt  
Bezug: MG-000 / SLG-000.2 / T-0008 / D-0117 / D-0118

## Nutzerentscheidung

V1 nutzt ein zwölfmonatiges Geschäftsjahr, das mit dem Kalenderjahr endet. Ein alternatives Wirtschaftsjahr kann in V2 geprüft werden; es wird dadurch nicht für V1 beschlossen.

## Rechtliche Einordnung

§ 240 Abs. 2 HGB sieht für Kaufleute ein Inventar zum Ende jedes Geschäftsjahrs vor und begrenzt dessen Dauer auf höchstens zwölf Monate. § 242 HGB verlangt grundsätzlich den Abschluss zum Geschäftsjahresende. Die Auswahl des Kalenderjahres als V1-Geschäftsjahr ist die konkrete Produktregel; diese Aussage behauptet nicht, dass das HGB für sämtliche Unternehmen zwingend das Kalenderjahr vorgibt.

Quellen: [§ 240 HGB](https://www.gesetze-im-internet.de/hgb/__240.html), [§ 242 HGB](https://www.gesetze-im-internet.de/hgb/__242.html).
