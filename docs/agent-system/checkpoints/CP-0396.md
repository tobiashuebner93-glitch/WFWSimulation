## Ergebnis

Der Query-Token an `run.js` ist der SHA-256 der konkreten Modulbytes. Die Logo-Selbstnavigation trägt denselben Token auf `run.html`. Die Entry-Regression berechnet den Hash selbst und prüft, dass Modul- und Logo-URL exakt an denselben `run.js`-Payload gebunden sind. Änderungen an `run.js` ohne passende Tokenaktualisierung schlagen daher in dieser Regression fehl.

Die statische Hostingumgebung im Repo kontrolliert keine HTTP-Cacheheader. Der lokale Python-Server liefert `Last-Modified`, aber weder `Cache-Control` noch `ETag`. Das Resultat verhindert nicht nachweisbar, dass ein Browser am unversionierten Direkteinstieg eine alte HTML-Kopie verwendet. Es wird nur die aktuelle HTML-/Run-Modul-Bindung und der versionierte Logo-Rücksprung belegt. Transitive statische Modulimporte werden nicht durch diesen Token gehasht.
