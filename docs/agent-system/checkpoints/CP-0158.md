## Fortschreibung

Der V1-Prototyp wurde um einen monatlichen Phasenabschluss ergänzt. A02 markiert beim Verarbeiten des letzten Kalendertags eines Monats den abgeschlossenen Monat. A03 speichert dafür eine idempotente Monatsübersicht mit Bankbestand zu Monatsanfang/-ende, im Monat ausgestellten Rechnungen und deren Netto-/SimTAX-Summen, Kundeneingängen nach Zahlungsdatum sowie Lieferungs- und Auftragsabschlusszahlen. A05 zeigt diese Angaben in der mobilen Finanzansicht. Ein Hinweis grenzt die Übersicht vom vollständigen BAB/Kostenabschluss und von nicht belegbaren Auftragsmargen ab. Keine unbekannten Betriebs-, Vorrats- oder Darlehenswerte wurden ergänzt.

README dokumentiert beide Serverstart-/URL-Varianten. CSS verwendet die vorhandene `--soft` Farbvariable für die Monatsmetriken.
