## A05-Integration

A05 hat die gemeinsame V3-Run-UI gegen die zweiphasige API integriert: Tag öffnen, Postfach/Anfragen prüfen, mit expliziten Kalkulationsangaben Angebot abgeben und Tag schließen. Angebotskalkulation und BAB-Klassifikation erhalten keine stillen Werte; optional wird eine explizite Testressourcenbasis angelegt. Angenommene Kundenaufträge erhalten Vertrags- und Operationsformulare; Arbeitsschritte werden manuell abgeschlossen. Keine automatische Lieferung, Kundenabnahme, Rechnung, Steuer-, Cash- oder Ledgerbuchung. UI kennzeichnet den lokalen In-Memory-Lauf als nicht persistent und das Marktfixture als synthetisch.

Lieferung: `prototype/v3/run.html`, `prototype/v3/run.js`, `prototype/v3/run.css`, `prototype/a05-t0069-run-ui-regressions.mjs`, `docs/simulation/a05-t0069-run-ui-integration-report.md`.
