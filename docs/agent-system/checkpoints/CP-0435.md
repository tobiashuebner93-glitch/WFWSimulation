## Ergebnis

Der Read/Propose-Lauf weist keine operative Materialbestellung im vorhandenen T-0066 Shared-Run-Modell nach. Der Makro-ETA-Projektor liest nur ein ausdrücklich im Makroevent übergebenes `openShipments[]`-Fixture. T-0066 speichert Materialbestände und Produktions-/Kundenarbeitspläne mit Arbeitsschrittstatus, aber keine Lieferantenbestellung mit Status, Positionsmenge, stabiler Bestellreferenz und erwarteter Liefer-ETA. A03 CP-0369 dokumentiert, dass das Makrofixture nicht gegen eine operative Beschaffungsverwaltung abgeglichen wird.

Ein Adapter ohne Änderungen an Modell/API ist damit nicht möglich. `projectDeliveryEta()` bleibt isolierte nichtbuchende Projektion und darf nicht so ausgegeben werden, als ändere sie eine reale Bestellung. Es wurden keine Lieferzeit- oder Verzögerungsannahmen gewählt, keine Produktdatenobjekte vorgeschlagen und kein Produktcode geändert.

Als nächster vorhandener Unternehmensanschluss kann A01 `getV3RunOperatingImpact()` aus dem bestehenden Codepfad nutzen: D-0169-Anfragen → tatsächliche Spieler-Awards → Arbeitsplanstunden → deklarierte Werktagskapazität/Auslastung. Die Projektion erzeugt keine weiteren Anfragen oder Finance-/Ledger-Wirkung und ist kein Ersatz für eine Beschaffungs-ETA.

Details, konkrete Module, notwendige spätere A03-Inputs, Grenzen und Mindestprüfungen stehen im [A02-Bericht](../../simulation/a02-t0063-t0066-open-order-eta-read-propose-cp0435.md).
