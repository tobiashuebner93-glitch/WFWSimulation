Damit liegt kein gleich langer, direkt vergleichbarer Vorher/Nachher-Messpunkt vor; eine prozentuale Verbesserung wird nicht behauptet. Der vollständige Jahresvektor und Schlussassertionen bleiben offen.

Der korrigierte Receipt-ID-Unique-Check bleibt aktiv. Der vorige unindizierte Testlauf hatte alle Monatsreconciliations bis Dezember bestanden, aber die falsche Erwartung von zwölf Zahlungseingängen; tatsächliche eindeutige Zahlungseingänge waren 692.
