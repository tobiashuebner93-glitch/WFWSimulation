## Ergebnis

Der Spieler kann bei einer fälligen Vollzahlung mit unzureichendem Cash manuell genau den Fehlbetrag aus dem freien Dispositionskreditrahmen ziehen. Danach wird die Rechnung vollständig bezahlt. Reicht der Rahmen nicht oder lehnt der Spieler ab, scheitert der Versuch vollständig; Teilzahlung, negatives Cash und automatischer Draw gibt es nicht.
