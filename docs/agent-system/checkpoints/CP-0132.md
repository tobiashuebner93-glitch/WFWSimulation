## Neuer Nutzerhinweis

Für eine Neuverschuldung oberhalb der 90-%-Grenze bis 100 % soll der Zinssatz auf Disponiveau steigen.

## Klärungsbedarf

D-0023 definiert den Dispozins als 8 % über dem individuell vereinbarten Unternehmenszinssatz. Noch zu bestätigen ist, welcher Unternehmenszinssatz dabei als Bezugsgröße für das Ziel bei 100 % Fremdkapitalquote gilt. Ohne diese Abgrenzung ist das Disponiveau nicht eindeutig berechenbar. Es wird keine Bezugsgröße oder Übergangsfunktion angenommen.
