Der lokale SimpleHTTP-Server lieferte keine Cache-Validatoren.

## Änderung

Ein A05-Generator traversiert und hasht den gesamten lokalen statischen Run-Modulgraphen aus `run.js`. `run.html` enthält nun eine relative Import Map, welche jedes Graphmodul auf dieselbe Datei mit `?graph=sha256-<Graphhash>` umleitet. Die Entry-URL bindet weiterhin exakt `run.js` und zusätzlich den Graphhash; der Self-Link enthält Entry-, CSS- und Graphhash. Damit erhalten auch unveränderte Einstiegsbytes neue Modul-URLs, wenn ein transitive Datei geändert wird, ohne Cache-Control/ETag oder Serverkonfiguration vorauszusetzen.

Der reproduzierbare Aktualisierungsschritt lautet:

```powershell
node prototype/v3/a05-v3-run-module-graph-cache.mjs --write
```

Der Cachetest prüft alle 20 Importmap-Ziele auf URL-Auflösung und Graphbindung und demonstriert, dass eine simulierte Änderung ausschließlich in einem transitiven Modul einen neuen Graphhash ergibt. Neutral-Vorauswahl, positive Fixture-ID, Datumvalidierung und Szenarioregeln bleiben unverändert. A02-Runtime und Finance-State blieben unberührt.
