## Änderung

Vor dem ersten Einsatz wird ein fester Agenturvertrag ausgewählt. Die drei Szenarioangebote schaffen den gewünschten Grundpreis-/Stundenpreis-Tausch:

- Flexibel: 0 €/Monat + 55 €/h
- Ausgewogen: 120 €/Monat + 43 €/h
- Hohe Auslastung: 300 €/Monat + 31 €/h

Die Preisstufen sind illustrative Spielangebote, keine Marktpreise. Nach Vereinbarung bleiben die Konditionen fest. Jede Einsatzbuchung speichert die Vertragsreferenz und Sätze. In einem Monat mit mindestens einer Buchung wird der Grundpreis einmal berechnet; hinzu kommen gebuchte Stunden zum vereinbarten Stundensatz. Alte Spielstände ohne Agenturvertrag behalten 45 €/h ohne Grundpreis. Entscheidung D-0135.
