## Nutzerentscheidung

Für V1 fällt der tatsächliche vollständige Kunden-Zahlungseingang auf den vertraglichen Fälligkeitstag, sofern kein ausdrücklich festgelegtes Verspätungsereignis eintritt. Der Zahlungseingang hat kein eigenes Liquiditäts-Gate. Spätere Szenarien können abweichendes Verhalten festlegen.

## Rechtsabgrenzung

Die §§ 271 und 286 BGB regeln Fälligkeit und Verzug, legen aber keine allgemeine Zahlungseingangsverteilung fest. V1s Gleichsetzung von Fälligkeit und Eingang ist eine vereinfachte Produktregel.

Quellen: [§ 271 BGB](https://www.gesetze-im-internet.de/bgb/__271.html), [§ 286 BGB](https://www.gesetze-im-internet.de/bgb/__286.html).
